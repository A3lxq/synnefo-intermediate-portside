# Case File 3: Portside

Case File 2 traced a document trail to a shipping subsidiary: **Portside**,
Halcyon's logistics arm. According to Priya Okonkwo-Reyes' notes, a
shipment manifest was quietly rerouted through a terminal that, on paper,
doesn't exist — and the portal that would normally show that routing has
"temporary" API documentation that was never taken down.

Priya's note on this file: "Everything here talks to something else.
Follow where the requests actually go, not just where the login page
is."
